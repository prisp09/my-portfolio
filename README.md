# My Portfolio

Source for [priyanshupatel.com](https://www.priyanshupatel.com).

Built with Next.js 16 (App Router), React 19, Tailwind CSS 4 and a three.js particle
scene (React Three Fiber) that morphs as you scroll. Content lives in
`src/constants/constants.ts`.

```bash
yarn install
yarn dev
```

`yarn build` produces the static site that Netlify deploys. Node 22 or newer.
